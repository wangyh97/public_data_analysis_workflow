# Documentation guide

This directory describes rules that apply across studies. Start with
[architecture](architecture.md), then [CLI and configuration](cli_and_config.md)
and [data contracts](data_contracts/README.md). Reproduction details are in
[reproducibility](reproducibility.md).

For a new study, follow [run a new study](how_to/run_new_study.md). For new
capabilities, see [add a data source](how_to/add_data_source.md),
[add an analysis](how_to/add_analysis.md), or
[add a plot](how_to/add_plot.md). Disease- and accession-specific facts belong
in an example or a run manifest, not in these general instructions.
