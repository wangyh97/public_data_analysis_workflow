# CRC 单细胞证据分析：METTL3、STRAP、PTBP1

本项目检验公共患者单细胞转录组是否支持三个候选基因与抗原呈递相关。用户已确认原输入 STARP 应为 **STRAP**。表达相关性不能证明候选基因直接调控抗原呈递，也不能代表细胞表面肽–MHC-I 蛋白量或肿瘤抗原特异性。

## 1. 数据来源与完整性的定义

输入目录是用户提供的 `single cell` 文件夹；原有文件只读。新下载、提取数据、脚本、表格和图片均在当前 `CRC_single_cell` 输出目录。

需要分别判断：

1. **文件级完整性**：官方清单、HTTP Content-Length、压缩文件 CRC/结尾、RDS/矩阵结构、SHA256。本地 SHA256 是复现标识，不能冒充官方校验和。
2. **内部一致性**：矩阵行列数、条形码唯一性、表达与注释对应、计数非负/整数、目标基因是否存在、样本是否重复。
3. **生物学覆盖**：数据库处理版/抽样版是否覆盖原研究全部细胞，是否只保留前后配对患者，是否只有 PBMC，以及肿瘤细胞是否有可靠恶性注释。

CellResDB 和 scCT-DB 是整理平台，不能自动当成两个独立研究。相同 GSE、患者、样本在不同平台出现时只作为处理方法敏感性比较。正式独立验证应以不同原始研究为单位。

数据依据与原始文献：

- [CellResDB CRC 页面](https://cellknowledge.com.cn/cellresponse/php_mysql/getDataSetByOrgan.php?disease=CRC)，[CellResDB 论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12264041/)。
- [scCT-DB 论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12807622/)，[数据库](https://scctdb.ncpsb.org.cn/)。
- [GSE205506](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE205506)，[原始论文，2023](https://pubmed.ncbi.nlm.nih.gov/37172580/)：dMMR/MSI-H CRC，toripalimab ± celecoxib；疗效终点为 pCR/non-pCR。
- [GSE236581](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE236581)，[原始论文，2024](https://pubmed.ncbi.nlm.nih.gov/38981439/)：连续采样的肿瘤、正常组织和外周血；数据库 R/NR 使用 RECIST，不能与 pCR 视作相同终点。
- scCT-DB 的 GSE232525 仅一个 CRC 患者，适合描述性配对展示；GSE130157 的 CRC 部分是外周血，不能检验肿瘤内浸润。

## 2. 预先定义的证据顺序

| 优先级 | 问题 | 分析单位及设计 | 解释范围 |
|---|---|---|---|
| 主要 | 肿瘤候选基因是否与 MHC-I/APM 共变 | 治疗前、明确恶性细胞；患者平均表达与 MHC-I/APM 分数的 Spearman 相关；患者 bootstrap 95% CI；BH 校正 | 肿瘤内转录关联 |
| 重要敏感性 | 是否仅反映 IFN、增殖或测序复杂度 | IFN、cell-cycle、平均检测基因数校正后的 partial rank correlation；逐患者内部相关性 | 区分共同程序驱动，但不等同因果 |
| 次要 | 是否与临床疗效相关 | 同一研究、同一采样阶段；患者伪 bulk CPM；R/NR Wilcoxon；至少每组 3 位患者 | 预治疗才可作为候选预测线索；样本少时只画点 |
| 次要 | 肿瘤基因与 T 细胞功能状态是否关联 | 同一肿瘤样本配对肿瘤基因与 T 细胞 cytotoxic、dysfunction、stem/memory、Treg 程序 | 功能程序不等同真正杀伤能力；dysfunction 与激活可重叠 |
| 次要 | 是否与 T 细胞比例关联 | T/所有回收细胞和 T/免疫回收细胞两个分母；患者级相关 | 细胞组成，不能叫绝对浸润密度 |
| 补充 | 治疗前后有何变化 | 同患者、相同组织来源；优先最早可比较治疗后阶段；配对差值 | 不能把残留肿瘤选择效应解释为药物直接作用 |
| 探索 | high/low 候选表达的通讯变化 | 应按患者肿瘤表达分组，组内每患者独立建模；至少多患者且细胞类型齐备；固定 CellChatDB 版本 | LR 转录共表达推断，不能证明肽–MHC/TCR 特异性识别 |

三个候选基因都进入同一预定义分析，不按显著性挑选基因。主分析使用连续表达；median high/low 只适合展示或通讯敏感性，不以细胞表达中位数把所有患者细胞混合后进行显著性检验。

## 3. 数据处理与统计细节

- 直接复用数据库/作者已经处理过的计数和注释。本轮不从 FASTQ 或未过滤 droplets 开始，也不声称重新运行了 doublet/ambient-RNA 清除；相关原始信息缺失时明确记录。
- scCT-DB `Malignant epithelial cell`，或 GSE236581 作者 `c91_Epi_Tumor` 用于恶性细胞分析。普通 Epithelial/Epithelia 单独标为 `Epithelial_uncertain`，不自动认定为癌细胞。`c90_Epi_MKI67` 不自动并入恶性类。
- 所有基因计数参与每个细胞的文库大小。保存的目标矩阵仅包含目标/预设功能基因，不使用该小矩阵总和作分母。
- 标准化为 `log1p(count/library*10000)`。模块分数为预定义基因的平均标准化表达，无目标基因与 MHC/APM 分数的重叠。主文分数是透明的均值程序分数，不称为 UCell/AUCell。
- 伪 bulk 为一个样本某细胞群原始计数求和，再按该群全基因总计数计算 CPM；`log2(CPM+1)`。候选基因的非参数比较不替代全转录组 edgeR/DESeq2 差异分析。
- 同患者、同阶段多个肿瘤样本在患者级表中等权平均。保留样本级源表以检查空间/部位异质性。
- 治疗前的 `Untreated` 不能解释为 NR；只在同平台、同研究、同患者的已知终点一致时回填 R/NR。冲突标记不强制解决。
- 去重按平台 + 原始研究 + 原始样本进行。GSE236581 的 `orig.ident=SeuratProject` 不是样本标识，必须使用 `Ident`。其他研究使用明确 GSM ID。
- GSE236581 I 为 Pre，II/III/IV 分别保留为 Post_II/III/IV。不得把所有 Post 当成独立患者重复，也不随意合并阶段。
- 恶性/上皮群至少 30 个细胞，T 至少 20 个，组成分析样本至少 200 个回收细胞；相关至少 6 位患者，调整分析至少 10 位，response 每组至少 3 位。它们是分析稳定性门槛，不是细胞质量过滤阈值；在配置文件中明确可调。
- 小样本 bootstrap 区间可能很宽，结果应同时看效应量、方向、区间、患者数及 leave-one-patient-out 稳健性，而不是只看 p 值。
- 两种疗效终点、不同治疗方案、MSI/MMR、部位和阶段可能混杂。若缺少可靠患者级 MSI/临床表，不会编造协变量；联合方案和 ICI-only 的结果需要分层敏感性分析。
- 配对组织 T 比例受消化、捕获、细胞存活、富集和 pCR 后肿瘤消失影响；不能视为每平方毫米浸润密度。后者应结合 IHC/mIF/空间转录组。

## 4. 图形与源数据

图形采用 R，定量网格/效应量图；白底、固定目标基因配色，默认宽 183 mm，文字通常 8–9 pt。每幅同时输出可编辑 PDF 与 300-dpi PNG；原始分析数值在 `tables/`。散点代表患者或明确注明的患者内部相关系数；不会用成千上万细胞的 p 值制造患者证据。

计划图：细胞类型表达图、患者反应分组图、完整相关性矩阵、MHC 效应及置信区间森林图、患者内部关联一致性图、配对变化图。显著与不显著结果全部输出。没有足够有效重复时输出 eligibility 表，不能生成虚假的统计结论。

## 5. 运行环境与文件

运行时路径、版本和实际命令另见 `运行说明.md` 与 `audit/*sessionInfo.txt`。项目不修改系统 R/Python，不安装新包。使用已有 R 4.4.2、Matrix、data.table、ggplot2、jsonlite；Python 使用标准库和已有 NumPy。

`analysis_config.json` 固定随机种子、模块基因、阈值和重采样次数。`audit/` 保存完整性检查、官方网页快照、下载链接/哈希、日志与去重记录。`derived/` 为可以重建的紧凑目标矩阵；`data/` 为原始 GEO 补下载和 scCT CRC 子集；`tables/`、`figures/` 为结果。

最终数值结论见 `结果报告.md`。该文件应明确区分已执行分析、因样本信息不具备而不适用的分析、以及需要依赖/额外临床信息才能执行的扩展。
