# 交付与核查说明

先读 `结果报告.md`，再读 `设计与复现说明.md` 和 `运行说明.md`。所有统计结果来自已执行脚本；CellChat 扩展现已执行，另见 CellChat补充报告.md 和 CellChat运行与设计.md。

## 文件

- `scripts/`：带注释的提取、核查、分析、绘图与敏感性分析代码。
- `analysis_config.json`、`run_analysis.ps1`：具体参数、运行时路径和复现入口。
- `tables/`：完整患者级结果、检验资格、效应、P/q 值和敏感性结果。
- `figures/`：PDF 矢量图和对应 PNG 预览。07 和 08 是独立研究主结果；02 为疗效组比较；03 为关联总览；其他图为来源比较和探索分析。
- `audit/`：数据字节数、SHA256、解压和维度检查、运行日志、运行环境及 PDF 核查。
- `data/GEO/`：补齐的公开原始表达矩阵及元数据。
- `derived/`：用于快速重复统计的中间数据。
- `CRC_code_results.zip`：代码、报告、统计表、图和核查记录的分享包；**不含大型 data/、derived/ 和 runtime/**。原工作目录可直接运行 analyses；仅解压分享包时，需按运行说明配置原始输入并运行 full。

## 图例及解读

R/NR 箱线图：点为患者/时间，箱体为第 25–75 百分位，中线为中位数，须延伸至 1.5 IQR 内最远观测值；图上展示原始患者点。每组患者数及检验资格见 analysis_eligibility.csv。未知恶性状态的上皮细胞单独展示。

关联热图：数值为患者级 Spearman rho；n 为该检验的完整患者数；星号为对应预定义检验族 BH q<0.05，不表示机制因果关系。

森林图：点为患者级 rho，线为患者 bootstrap 的边际 95% 区间。散点图：一个点为一名患者的汇总值，颜色为临床结局。不同队列的临床结局定义见方法；不合并作统一疗效模型。
